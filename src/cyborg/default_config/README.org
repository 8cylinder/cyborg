
* Systemd (recommended)
Two scripts handle automated backups via systemd user units.

** Setup
1. Copy the default config if you haven't already:
   #+begin_src shell
   cyborg config copy
   #+end_src

2. Edit =~/.config/cyborg/systemd-backup.bash= and set the profiles you
   want to run (they must match section names in =config.ini=).

3. Run the install script as root:
   #+begin_src shell
   sudo bash ~/.config/cyborg/systemd-install.bash
   #+end_src

** What gets installed
Three units are written to =/etc/systemd/system/= and enabled:

| Unit                  | Purpose                                    |
|-----------------------+--------------------------------------------|
| =cyborg-backup.service= | Oneshot unit that runs =systemd-backup.bash= |
| =cyborg-backup.timer=   | Fires on boot, every 2 h, and on wake      |
| =cyborg-hooks.service=  | Runs before sleep and before shutdown      |

Wake-up coverage is handled by =Persistent=true= on the timer: if a
scheduled run was missed while the machine was asleep or off, systemd
fires it immediately when the system comes back up.

** Useful commands
#+begin_src shell
  systemctl list-timers                  # show next scheduled run
  systemctl status cyborg-backup.timer
  systemctl status cyborg-hooks.service
  journalctl -u cyborg-backup.service   # view backup logs


  # All cyborg unit logs
  journalctl -u "cyborg-*"

  # Specific units
  journalctl -u cyborg-hooks.service
  journalctl -u cyborg-backup.service
  journalctl -u cyborg-backup.timer

  journalctl -u cyborg-hooks.service; \
      journalctl -u cyborg-backup.service; \
      journalctl -u cyborg-backup.timer

  # Follow live output
  journalctl -u cyborg-backup.service -f

  # Last boot only
  journalctl -u "cyborg-*" -b

  The backup script itself also writes to log files:

  # Timestamp log (written on every run)
  ~/.config/cyborg/log-date.log

  # Per-profile logs (once you uncomment the profile loop in systemd-backup.bash)
  ~/.config/cyborg/log-nas.log
  ~/.config/cyborg/log-borgbase.log

  To check timer status and when the next run is scheduled:

  systemctl --user list-timers cyborg-backup.timer
#+end_src


* Crontab (alternative)
Run every two hours during the day, write to a log called =~/cyborg.log=.  Or
two profiles every 2 hours at 15 min after the hour

#+begin_src text
  0  8,10,12,14,16,18,20  *  *  *  $HOME/.local/bin/cyborg run nas >> $HOME/cyborg.log
  15  */2  *  *  *  $HOME/.local/bin/cyborg run nas >> $HOME/.config/cyborg/log-nas.log 2>&1 ; $HOME/.local/bin/cyborg run borgbase >> $HOME/.config/cyborg/log-borbase.log 2>&1
#+end_src

* Logrotate setup
in =/etc/logrotate.d= create a file called =cyborg=. Add the
following to it.
#+begin_src text
/home/sm/.cyborg/log {
    daily
    size 1M
    rotate 7
    compress
    missingok
}
#+end_src
